A material that forgets

Why forgetting is the feature

It sounds backwards. A computer that forgets? But think about what the alternative means. If a material's response depends on something that happened to it last week — something you cannot see and did not record — then the same input gives you different answers, and you can never trust the result. The material is not a computer. It is a machine for producing irreproducible numbers.

So the requirement is precise: recent history should matter, distant history should not. That is fading memory, and it is the one property that has to be demonstrated of any candidate substrate before anything else is worth measuring.

Drag relaxation time and watch the trade-off appear. A fiber that forgets fast becomes reproducible quickly, but cannot reach far back. A fiber that forgets slowly holds more of the past, and takes far longer to settle into agreement. You cannot have both, and where you sit on that dial should be decided by the task.

Push it far enough and the verdict turns to NOT YET. That is not the same as failing. The gap is still visibly falling when the test runs out; the material would settle, given a longer look. Reporting that honestly matters, because a slow substrate and a broken one look alike if you only ever watch for a fixed interval.

Then press Add a latching mode. This is not a contrivance: it gives the fiber a bistable polarisation — the switchable kind found in crystalline glycine — and conditioning drops the two fibers into opposite states. Nothing afterwards can shake them out. The gap stops decaying and simply sits there, and the two fibers disagree forever about an input they both received identically.
